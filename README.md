# scp-graphfs-mcp

> **Claim:** Curated protein-complex membership (CORUM, EBI Complex Portal) is a better prior for **reconstructing a cell's protein state from incomplete single-cell proteomics measurements** than data alone, than generic PPI networks (STRING), and than a degree-preserving shuffled version of the same graph.

**Status:** under construction for the OSI Hackathon (Oct 21–22, 2026). The benchmark has not been run yet. This README will report the result, whichever way it goes.
